# ДЗ-17: Статистика в OSINT

| Файл | Зміст |
|---|---|
| `analysis.py` | Розрахунки для завдань 1–3, бонусу та чисел до завдання 4 |
| `output.txt` | Повний вивід скрипта |
| `ВІДПОВІДІ.md` | Таблиці та пояснення до завдань 1–4 |
| `ЗАПИСКА.md` | Аналітична записка до завдання 4 (до 300 слів) |
| `data/hw17_water_posts.csv` | Вхідні дані з Google Drive курсу (90 днів) |

**Бібліотеки:** Python 3.10+, `pandas`, `numpy`, `scipy`.

```bash
pip install pandas numpy scipy
python analysis.py                  # або: python analysis.py шлях/до/hw17_water_posts.csv
```

**Методичні рішення:**
- Квантилі рахуються лінійною інтерполяцією (за замовчуванням у pandas/numpy).
- Для порівняння періодів використано тест Велча; тест Манна–Уітні додано як перевірку на стійкість.
- Поправка Бонферроні застосована до 5 метрик.
- Автокореляцію враховано через n_eff і тест на тижневих блоках.
- Частковий коефіцієнт кореляції рахується як кореляція залишків після регресії на `young_channels`.
