# Поиск по нику (Sherlock, Maigret, WhatsMyName)

Легитимный способ закрыть пивот «по нику»: перечисление **публичных** профилей по имени пользователя
на сотнях сайтов. Это open-source инструменты, работающие по публично доступным страницам, —
не дата-брокеры и не пробив по утечкам.

## Дизамбигуация (важно)

- **Sherlock (OSS)** — проект `sherlock-project/sherlock` на GitHub, проверяет наличие ника на ~400+ сайтах.
- **«Sherlock-бот»** из разбора [[Пробив и дата-брокеры]] — это **другое**: платный Telegram-бот пробива
  по слитым базам. Одинаковое имя — разные вещи. Не путать.

## Инструменты

| Инструмент | Что делает | Плюсы | Минусы |
|---|---|---|---|
| **Sherlock** (OSS) | Проверка ника на 400+ сайтах | Быстрый, популярный, бесплатный | Много ложных срабатываний; нужен ручной отсев |
| **Maigret** | Fork-развитие: + извлечение данных профиля, отчёты | Богаче по данным, HTML/PDF-отчёты | Медленнее; шумит; требует проверки |
| **WhatsMyName** | Единый открытый список сайтов (данные), движок-агностик | Качественная база сайтов, низкий шум | Сам по себе — только данные; нужен клиент/веб-UI |

## Дисциплина

- Совпадение ника — **зацепка (грейд C/D)**, не доказательство. Поднимай достоверность, только если
  профиль независимо подтверждён (правило трёх).
- Ники переиспользуют, сквоттят и копируют при имперсонации — проверяй подлинность.
- Применяй в рамках gate авторизации; для учёбы — на **своём** нике (см. [[Удаление своих данных]]).
