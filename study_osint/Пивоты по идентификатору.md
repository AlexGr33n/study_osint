# Пивоты по идентификатору

Расследование почти всегда отталкивается от **одного идентификатора**. Полезно держать карту:
от чего можно оттолкнуться и каким **законным** открытым источником это закрыть — вместо пробива
по утечкам (почему не пробив → [[Пробив и дата-брокеры]]).

| Пивот | Законный открытый источник |
|---|---|
| **email** | HIBP (самопроверка **своего** адреса), EmailRep, Hunter (корпоративные паттерны); валидация без отправки письма |
| **имя пользователя / ник** | OSS: Sherlock, Maigret, WhatsMyName — перечисление по публичным профилям → [[Поиск по нику]]. Ник — зацепка, не доказательство |
| **фото** | Обратный поиск (Google Lens, Yandex, TinEye), хронолокация, геолокация по признакам |
| **телефон** | Валидация формата/оператора (libphonenumber), публичные объявления и бизнес-листинги. Определители на краудсорсе приватных контактов — вне рамок |
| **авто / недвижимость / ИНН / кадастр** | Официальные реестры: ФНС/ЕГРЮЛ, Росреестр, проверки ГИБДД — первичные источники |
| **домен / IP** | WHOIS/RDAP, DNS, CT-логи, passive DNS (см. навык: `references/attack-surface.md`) |
| **соцсети** | Публичные профили и официальные API — без обхода авторизации |
| **компания / контрагент** | ЕГРЮЛ/ЕГРИП, OpenCorporates, судебные и регуляторные записи, СМИ |

## Дисциплина

- Один и тот же идентификатор на разных платформах — **зацепка**, а не доказательство. Верифицируй личность
  до объединения данных (правило трёх; разрешение однофамильцев — см. навык `references/verification.md`).
- Останавливайся перед любой авторизационной стеной и перед любой краденой/слитой базой.
- Фиксируй происхождение каждой находки (источник + время UTC) — гигиена доказательств.
