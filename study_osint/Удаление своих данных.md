# Удаление своих данных из баз и ботов

«OSINT наоборот»: прогнать метод против **себя** (или согласного коллеги), увидеть свою экспозицию
и зачистить её. Это самый безопасный способ отработать каждую технику и единственный, где цель —
сам исследователь. Поэтому `ethics_check: passed` по определению.

## Шаг 1. Карта своей экспозиции

Пройди пивоты из [[Пивоты по идентификатору]] по своим идентификаторам:
- email → HIBP: в каких утечках засветился адрес.
- ник → [[Поиск по нику]]: где есть публичные профили (в т.ч. забытые).
- имя/телефон → общий веб-поиск, веб-архивы (Wayback) — что индексируется и что осталось в кэше.
- фото → обратный поиск: где используется твоя аватарка.
- Зафиксируй находки как список активов (что, где, какой грейд) — это твой план зачистки.

## Шаг 2. Снижение экспозиции

- **Аккаунты:** удали/заархивируй забытые профили; ужесточи приватность у активных; отвяжи кросс-ссылки.
- **Утечки:** смени пароли из засвеченных утечек, включи 2FA, отзови старые сессии и токены.
- **Поисковики:** запроси удаление устаревших/чувствительных результатов (формы Google/Яндекс «удалить информацию о себе»).
- **Архивы:** где уместно — запрос на исключение из веб-архива.

## Шаг 3. Удаление из баз пробива/дата-брокеров

Контекст — см. [[Пробив и дата-брокеры]]. У ряда операторов есть процедура удаления/сокрытия
по запросу субъекта данных.
- Используй **официальную форму удаления** оператора или обращение на основании **152-ФЗ / GDPR**
  (право на удаление). Фиксируй дату запроса и ответ.
- Не «пробивай» себя через платный бот ради проверки: это кормит ту же экосистему и логирует запрос.
  Оценивай результат по публичным источникам и по ответу оператора на твой запрос об удалении.

## Шаг 4. Поддержка

- Повторяй карту экспозиции периодически (еженедельный/ежемесячный diff — см. дисциплину бюджета времени в навыке).
- Новая находка → новый шаг зачистки. Веди журнал как `practice-log`.

> Это защитная практика. Те же шаги для **чужого** профиля без согласия — слежка, а не самооценка; вне рамок.
