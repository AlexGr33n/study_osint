# Контрольный прогон AI-детекторов

Score детектора нельзя интерпретировать без **контроля**. Рядом с подозрительным файлом прогоняй
заведомо настоящий снимок того же события, по возможности в том же состоянии (та же платформа, похожее сжатие).

## Шаги

1. Подобрать контроль: официальное фото события, настоящую обложку того же номера, найденный оригинал.
2. Прогнать фейк и контроль через **минимум 2 независимых** детектора ([[Hive Detect]], [[Sightengine]]; для
   водяного знака — [[SynthID Detector]]).
3. Записать: детектор, версию или дату, score, атрибуцию генератора, состояние файла (оригинал / пережатый / скриншот).
4. Детектор считается информативным, только если он **разделяет** фейк и контроль.

## Что показал ДЗ-04

| | BRICS (генерация) | Hebdo (иллюстрация) | Стармер (AI-правка) |
|---|---|---|---|
| Hive: фейк / контроль | 99,9 % / 0 % | 99,9 % / 0,5 % | **0,5 % / 0,4 %** (deepfake 0,1 / **20,8 %**) |
| Sightengine: фейк / контроль | 99 % / 0 % | 99 % / 0 % | **1 % / 1 %** |
| Ateeqq (HF) | 1,00 / 1,00 | 1,00 / 1,00 | 1,00 / 1,00 |

- Коммерческие детекторы работают на полной генерации и слепы к локальной правке.
- Без контроля Ateeqq выглядел бы идеальным детектором («AI» на всех фейках). На самом деле он отвечает «AI» на всё.
- Атрибуция генератора ненадёжна. Надёжен только водяной знак (SynthID) или C2PA.
- Score — вероятность, а не вердикт. Вердикт строится на совпадении независимых уровней.
