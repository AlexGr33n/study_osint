# Hive Detect

Бесплатный веб-детектор Hive (hivedetect.ai): изображения, видео (по кадрам), аудио. Можно загрузить файл или дать URL.

- **Выдаёт:** % AI-generated, % deepfake, атрибуцию генератора (gptimage2, qwen, sora, flux… около 100 классов) и
  проверку **Content Credentials (C2PA)**.
- **Вход:** без аккаунта. Загрузка файла или ссылка на медиа.
- **Сильное:** полная генерация. В ДЗ-04 дал 99,9 % на обоих фейках и ≤ 0,5 % на контролях, цифры совпали с фактчекерами.
- **Слабое:** AI-правка настоящего фото (кейс Стармера — 0,5 %). Ложный «deepfake» 20,8 % на настоящем селфи.
  Атрибуция генератора расходится с водяным знаком.
- **Также есть:** X-бот (@hive_ai) и расширение для Chrome.
