# Mastodon API

Официальный REST API любого инстанса Mastodon. Публичные ленты доступны **без токена**.

- **Хештег-лента:** `GET https://<instance>/api/v1/timelines/tag/<tag>?limit=40`. Максимум 40 на страницу,
  ответ идёт от новых к старым.
- **Пагинация по id:**
  - `min_id` — сразу новее id, для инкрементного сбора;
  - `max_id` — старее, для backfill;
  - `since_id` — самые свежие новее id (после паузы оставляет дыру).

  Готовые курсоры есть и в заголовке `Link` (`rel="next"` / `rel="prev"`).
- **Лимиты (замер 29.10.2026):** `X-RateLimit-Limit: 300` на окно 5 минут. Окно сбрасывается на границах :x0/:x5.
  Счёт у каждого инстанса свой; по документации анонимный клиент считается по IP, клиент с токеном — по аккаунту.
- **Поля статуса для канонической модели:**
  - `uri` (стабильный ActivityPub-id, ключ dedup) и `url`;
  - `created_at` (UTC);
  - `content` (HTML), `language`, `media_attachments`, `visibility`;
  - `account.acct` — для удалённых авторов `user@domain`, для локальных только `user`.
- **Сигналы согласия:** `account.indexable` (готов ли автор к полнотекстовому поиску) и `account.noindex`.
  Уважай отказ: не собирай такие посты.
- **`account.bot`** — флаг автоматического аккаунта. Без него не отличить ленту медиа-мостов от обсуждения людьми.
- **Совместимые серверы** (Pleroma, Akkoma, GoToSocial) отдают тот же API, но id у них нечисловые.

## Ограничения
- Хештег-лента инстанса — только то, что этот инстанс получил через федерацию ([[Хештег-ленты Fediverse]]).
- `accounts/lookup` находит только аккаунты, известные инстансу. На пробе один запрос вернул 200 с телом не-JSON.
- Правки и удаления постов в ленте не видны: собранная запись — снимок на момент сбора.
