# FxTwitter API

Публичный JSON-прокси для отдельных твитов X: `https://api.fxtwitter.com/<user>/status/<id>`. Работает без логина.

- **Выдаёт:** `created_at` (UTC), `created_timestamp`, просмотры, лайки, ретвиты, автора (подписчики, описание),
  цитируемый твит, `replying_to_status` и прямые URL медиа (`pbs.twimg.com/media/<id>.jpg?name=orig`).
- **Зачем в OSINT:** точное время первой публикации и самая крупная копия медиа. Профили и ленты без логина
  в X не видны, а отдельный твит через этот прокси — виден.
- **Самая крупная копия:** `https://pbs.twimg.com/media/<id>?format=jpg&name=orig`. Это всё равно пережатие X
  (q≈83–85, без EXIF), но лучшего публично нет.
- **Ограничения:** сторонний сервис, не официальный API. Поиска нет. Цифры меняются со временем, поэтому записывай дату снятия.
