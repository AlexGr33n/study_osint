# Пробив и дата-брокеры

Разбор экосистемы русскоязычного «пробива» на примере двух GitHub-аккаунтов. Вывод: **как
инструментарий — вне рамок нашего навыка** (см. `../.claude/skills/osint-research/references/ethics-and-legal.md`).
Знать эту экосистему нужно: это и ландшафт угроз, и то, от чего мы защищаем субъекта (см. [[Удаление своих данных]]).

## Что это на самом деле

Оба аккаунта — **не open-source инструменты**, а сети SEO/партнёрских репозиториев-витрин:
кода нет, в каждом только README-лендинг с реферальными ссылками на Telegram-боты пробива.

- **`osint-and-search`** (~65 репо) — каталог-навигатор по пробиву: по телефону, email, ФИО,
  паспорту, авто/VIN, правам, ИНН, адресу, кадастру, номеру банковской карты, фото, нику, IP,
  по соцсетям и мессенджерам. Есть откровенно слежечные темы: «найти бывшую», «проверка на измену», деанон Telegram.
- **`glaz-boga-telegram`** (8 репо) — витрины конкретных ботов: Глаз Бога, Funstat, Sherlock, Himera, UsersBox, Vektor, Telelog, Enigma.

Даже лендинги, называющие себя «законными» и «в рамках законодательства РФ», в тексте прямо пишут,
что боты агрегируют **«утёкшие базы»** и **«закрытые базы»**. Это и есть пробив — деанонимизация
частных лиц по слитым/краденым персональным данным.

## Плюсы / минусы ключевых ботов

«Плюсы» = почему люди их используют; «минусы» = реальные проблемы.

| Инструмент | Что делает | Плюсы (заявленные) | Минусы / риски |
|---|---|---|---|
| **Глаз Бога** | Пробив по телефон/ФИО/авто/фото/соцсети | Широкий охват, известность, удобный ТГ-интерфейс | Работа на слитых базах; судебные дела против оператора; масса фейк-клонов; логирует твои запросы |
| **Himera** | Пробив, «поиск контрагентов», большие БД | Позиционируется как «законный», B2B-уклон | Та же агрегация утечек; «законность» — маркетинг, не факт |
| **Funstat / Telelog** | Telegram-аналитика: членство в группах, активность, история | Деанон/профилирование ТГ-аккаунта, связи | Сбор данных о приватной активности; деанон частных лиц; серо-чёрная зона |
| **Sherlock (бот)** | Пробив по данным | Дёшево | ⚠️ Не путать с OSS-инструментом (см. [[Поиск по нику]]); бот = пробив по утечкам |
| **UsersBox / Vektor / Enigma** | Агрегаторы пробива по телефон/email/ФИО | Разные БД, бесплатные пробы | Утёкшие данные; скам-клоны; качество/актуальность не проверяемы |
| **Аналоги GetContact** | Теги/имена по номеру телефона | Определение звонившего | Краудсорс приватных контактов без согласия; инвазивно |

Общий минус для всех: **нет верификации источника** (нарушает принцип независимых источников и правило трёх),
данные могут быть ошибочны → ложная атрибуция.

## Почему вне рамок

Запрос по чужому телефону/паспорту/ФИО в слитой базе — это:
- **152-ФЗ** (обработка перс. данных без основания), **ст. 137 УК РФ** (неприкосновенность частной жизни),
  **ст. 272 УК РФ** (доступ к охраняемой компьютерной информации); для субъектов из ЕС — **GDPR**.
- Против оператора «Глаз Бога» в РФ были реальные дела — риск не теоретический.
- Практика: **твои запросы логируются** оператором, много **скам-клонов** и **ханипотов**, данные часто устаревшие.

Маркетинговая плашка «законный» этого не меняет. В нашем методе такие сервисы заменяются **законными
пивотами** → см. [[Пивоты по идентификатору]].

## Что отсюда полезно

1. **Таксономия пивотов** — хорошая карта «от какого идентификатора отталкиваться» → [[Пивоты по идентификатору]].
2. **Защита цифрового следа** — тема «как удалить свои данные» легитимна → [[Удаление своих данных]].
3. **Дизамбигуация** — «Sherlock-бот» ≠ OSS Sherlock → [[Поиск по нику]].
