# osinter.dev — сайт курса «AI для OSINT 2026»

Сайт курса на Quartz v5: слайды уроков (текстом, с заметками докладчика), ДЗ с критериями, справочники, промпты,
шаблоны, проекты и кейсы. Исходники — публичный репозиторий `popovvasile/osint-ai-2026` (Markdown, папка `content/`),
поэтому сайт удобнее читать **клоном репозитория**, чем обходом HTML. Курс обновлён в июле 2026; формат — 16 уроков,
практика, защита курсовых; язык — украинский. Девиз: «ни один факт не достоверен до верификации».

URL страницы = путь файла в `content/` без `.md`, пробелы → `-`, `&` → `-and-` (напр. `03-Матеріали/Соціальні-мережі/Capture--and--Preservation`).
