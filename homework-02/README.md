# ДЗ-02: Промптинг, галюцинації та RAG

Домашнє завдання з промптингу, виявлення галюцинацій LLM, RAG і захисту аналітичного
workflow від prompt injection. Виконано **базовий + просунутий** рівні повністю.

## Методологія і чесні застереження

1. **Модель і cutoff.** Я — Claude **Opus 4.8** (knowledge cutoff ~**січень 2026**), а не
   безкоштовний Sonnet із завдання (~серпень 2024). Це чесно враховано: для завдання 3
   (RAG) подію обрано **після мого cutoff** (жовтень 2026), щоб ефект «модель не знає» був
   справжнім саме для мене.
2. **«LLM без пошуку».** Відповіді «з пам'яті» (Б1 поганий промпт, Б2 Крок 1, П1 Джерело A)
   згенеровано **без жодних інструментів** — це реальна відповідь моделі з тренувальних даних.
3. **«LLM із пошуком».** Ролі Perplexity/RAG (П1 Джерело B, П2 Крок 1) виконано **реальним
   веб-пошуком** із цитуванням; усі посилання — клікабельні.
4. **Запечатування (Б2).** Відповідь з пам'яті про Вовка записано в окремий файл **до**
   будь-якого пошуку по ньому і не редаговано після — щоб не підлаштувати оцінку заднім числом.
5. **Етика.** Усі особи — публічні; використано лише відкриті джерела; компанія в завданні 5
   вигадана. Жодної приватної особи не профільовано.

## Результати стисло

- **Б1:** структурований промпт прибрав вигадані поля (освіта, місто) і дав валідний JSON
  із `null` для відсутніх даних; поганий — впевнені домисли без джерел.
- **Б2:** з 18 перевірених фактів — **50% правда, 22% помилки (галюцинації), 28% не
  підтверджено**. Модель вигадувала саме конкретику (місто виробництва «Жовква» замість
  Прилбичів, ВНЗ, рік заводу в Литві, «частку ринку 30%») — впевненим тоном, без застережень.
- **П1 (RAG):** без пошуку — чесне «не знаю»; Perplexity — свіжо й з посиланнями, але
  некритично переповідає **заяви хакерів** як факти; ручна звірка першоджерел виявила
  розбіжності ($400k є в одних ЗМІ і немає в інших; 7,9 млн записів — неперевірена заява).
- **П2 (пайплайн):** 4 кроки дали аудитований результат — кожна сутність із грейдом A/B/C/D;
  профіль спирається лише на A/B, слабкі факти винесено в **gaps** із планом дошуку.
- **П3 (injection):** реальні прогони в Claude.ai (Opus 5.5). Без захисту модель команду
  **не виконала** і сама попередила про прихований коментар, але вільним текстом; із захистом —
  стандартний тег `[УВАГА: ВИЯВЛЕНО СПРОБУ PROMPT INJECTION]` першим рядком. Обидва
  висновки коректні (ВИСОКИЙ ризик): захист зробив попередження машинозчитуваним.

## Головний висновок

Головне, що змінилось у розумінні: **якість відповіді LLM визначає не модель, а те, що і
як ти в неї вклав**. Той самий Claude на один об'єкт дає або впевнену вигадку, або
машиночитаний факт із `null` там, де даних немає — різниця лише в структурі промпту.
Галюцинації не випадкові: модель найвпевненіша рівно там, де вигадує конкретику, тож
«звучить переконливо» і «є правдою» — незалежні речі. RAG знімає проблему cutoff, але не
знімає потреби перевіряти: він так само впевнено переповідає неперевірені заяви. А
аудитований пайплайн (екстракція → грейдинг → синтез лише на A/B) і захисний system prompt
проти injection — це не ускладнення заради ускладнення, а базова гігієна, що перетворює
LLM із «оповідача» на керований і перевірюваний аналітичний інструмент.
