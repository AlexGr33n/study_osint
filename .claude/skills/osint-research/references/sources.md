# Каталог источников и техник (легитимные открытые источники)

Категоризированная карта того, *какие виды* открытых источников существуют и для чего каждый годится.
Это учебный справочник, а не конвейер «в одну кнопку». Каждая техника здесь предполагает,
что gate авторизации Фазы 0 пройден и ты остаёшься на публичной стороне любого
контроля доступа. Предпочитай первичные/авторитетные источники агрегаторам.

Инструменты меняются, категории — нет. Изучи категорию, затем выбери актуальный инструмент внутри неё.

## §Поиск — вширь

- **Общий веб-поиск** (встроенный `WebSearch`) — первый проход по любому идентификатору. Используй кавычки
  для точной фразы; добавляй уточнитель (организация/город) против однофамильцев.
- **Поиск по новостям/архивам** — пресса, официальные сообщения, новости судов/реестров.
- **Продвинутые операторы** — `site:`, `intitle:`, `filetype:`, точные фразы. Самый
  результативный навык в OSINT; отрабатывай их прежде, чем тянуться к платному инструменту.
- **Несколько поисковиков** — разные индексы выдают разные страницы (западный поисковик и
  региональный расходятся с пользой для дела). Кросс-поисковая проверка — дешёвый источник подтверждения.
- **Веб-архивы** (Wayback Machine, archive.today) — восстанавливают изменённые/удалённые публичные страницы;
  сравнивай страницу во времени. Отлично подходят для подтверждения, что утверждение существовало на определённую дату.

## §Загрузка и чтение — вглубь по известному URL

- **`WebFetch`** (встроенный) — вытягивает публичную страницу в markdown, и ей можно задать вопрос.
- **Сервисы чтения/извлечения** — очищают текст статьи, когда страница замусорена.
- Останавливайся перед авторизационными стенами/пейволлами. Если страница требует входа, на который у тебя нет прав, она вне рамок (scope).

## §Инфраструктура — домены, IP, email, технологии

Для технических стартовых идентификаторов (домен, IP или почтовый домен):
- **WHOIS / RDAP** — регистрант (часто скрыт), даты, регистратор, серверы имён.
- **DNS-записи** — A/AAAA/MX/TXT/NS; история passive-DNS связывает домены, делившие один IP.
- **Прозрачность TLS-сертификатов (Certificate Transparency)** — сертификаты раскрывают поддомены и связанные имена хостов.
- **Поиск по IP / ASN** — хостинг-провайдер, геолокация (грубая — в лучшем случае город, не адрес).
- **Валидация email** — синтаксис/MX/доставляемость *без* отправки; подтверждает, что ящик может существовать.
  **Не** запрашивай дампы утечек; для защитных самопроверок используй авторитетные сервисы уведомлений
  об утечках только против **своих собственных** адресов.
- **Фингерпринтинг технологий сайта** — CMS, идентификаторы аналитики, фавиконы; общие аналитика/идентификаторы могут связывать сайты.

Применение: атрибуция инфраструктуры, триаж фишинга/threat-intel, подтверждение того, кто управляет сайтом.

## §Аккаунты и имена пользователей — только публичные профили

- **Перебор имён пользователей** — один и тот же ник на разных платформах — это *зацепка*, а не доказательство
  (ники переиспользуют и захватывают). Всегда верифицируй личность перед объединением (см. `verification.md`).
- **Публичные поля профиля** — био, дата регистрации, ритм публичных постов, привязанные сайты. Только публичное.
- **Официальные/верифицированные индикаторы** — значки верификации, обратные ссылки с авторитетного сайта.

Никогда: автоматизированный скрейпинг за авторизацией, переиспользование учётных данных или доступ к приватному контенту / контенту только для друзей.

## §Медиа и геолокация — изображения и видео

- **Обратный поиск по изображению** (несколько поисковиков) — находит ранние/другие использования фото; переиспользованное
  изображение — главный признак дезинформации/сокпаппета. Делай это *до* того, как доверять любой аватарке профиля.
- **Метаданные изображения (EXIF)** — камера, метка времени, иногда GPS — *если присутствуют в файле, которым ты
  владеешь на законных основаниях*. Большинство платформ срезают EXIF при загрузке; отсутствие ничего не доказывает.
- **Хронолокация** — определение времени по теням, метеосводкам, датам событий в кадре.
- **Геолокация по визуальным признакам** — вывески, язык, архитектура, форматы автомобильных номеров,
  положение солнца, рельеф. Подтверждай по картам/панорамным снимкам улиц. Ключевой, хорошо обучаемый навык для CTF.
- **Проверки на манипуляцию** — анализ уровня ошибок (ELA), выявление несостыковок, происхождение (provenance)/C2PA, где
  доступно. Относись к вердикту любого отдельного инструмента как к гипотезе, а не доказательству.

Полный порядок проверки фото/видео/аудио на подлинность (провенанс → метаданные/C2PA → сигнал → физика сцены →
детекторы → вердикт) — навык `media-verification`.

Граница: геолокация **снимков публичных событий/достопримечательностей** для CTF допустима; реконструкция
**домашнего адреса или местоположения в реальном времени** частного лица — вне рамок (см. `ethics-and-legal.md`).

## §Публичные записи и реестры

- Реестры компаний/бизнеса, судебные записи, регуляторные документы, санкционные/PEP-списки,
  патенты, академические публикации, государственные порталы открытых данных.
- Это **первичные источники** — цени их выше блогов/агрегаторов.
- Доступность и законность использования различаются по юрисдикциям; фиксируй источник и дату.
- **Санкции/PEP одной точкой:** OpenSanctions (`/search`, `/entities/{id}?nested=true`, `/match`; score — кандидат,
  не вердикт). Офшорные выдержки журналистов — ICIJ OffshoreLeaks. Украина: ЕДР через data.gov.ua, OpenDataBot /
  YouControl; мир: OpenCorporates (ключ по заявке), GLEIF/LEI. North Data — только через сайт, скрапинг запрещён ToS.
- Общая модель сущностей и связей — FollowTheMoney (см. `entity-resolution.md`).
- Без ключа: crt.sh (поддомены из CT), ip-api (гео/ASN — уровень C), Wayback CDX, Wikidata.

## §Пивоты по идентификатору → законные источники

Расследование часто отталкивается от одного идентификатора. Для каждого — законный открытый
эквивалент (не дата-брокеры и не пробив по утечкам; см. `ethics-and-legal.md`).

- **email** → HIBP (самопроверка **своего** адреса), EmailRep, Hunter (корпоративные паттерны); валидация без отправки.
- **имя пользователя / ник** → OSS: Sherlock, Maigret, WhatsMyName (перечисление по публичным профилям). Ник — зацепка, не доказательство (§Аккаунты).
- **фото** → обратный поиск (Google Lens, Yandex, TinEye), хронолокация, геолокация по признакам (§Медиа).
- **телефон** → валидация формата/оператора (libphonenumber), публичные объявления/бизнес-листинги. Определители на краудсорсе приватных контактов — вне рамок.
- **авто / недвижимость / ИНН / кадастр** → официальные реестры (ФНС/ЕГРЮЛ, Росреестр, проверки ГИБДД) — первичные источники (§Публичные записи).
- **домен / IP** → WHOIS/RDAP, DNS, CT-логи, passive DNS (§Инфраструктура; также `attack-surface.md`).
- **соцсети** → публичные профили и официальные API — без обхода авторизации (§Аккаунты).

> **Вне рамок навыка:** Telegram-боты «пробива» и дата-брокеры (Глаз Бога, Funstat, Himera, UsersBox и т.п.)
> работают на утёкших/краденых базах и служат деанону частных лиц — это нарушает `ethics-and-legal.md`
> (152-ФЗ, ст. 137/272 УК РФ, GDPR). Полный разбор — в хранилище, заметка «Пробив и дата-брокеры».

## §Региональная заметка

Покрытие различается по регионам. По субъектам из СНГ/русскоязычным западные поисковики индексируют хуже;
региональные поисковики, архивы и реестры закрывают пробелы. Для любого региона изучи его авторитетные
реестры и доминирующий поисковик — именно там живут первичные источники.

## Инструменты на основе API (опционально, для авторизованной работы)

Платные исследовательские API (поиск, семантический поиск, ридеры, скрейпинг-платформы) могут ускорить
*авторизованный сбор в рамках (scope)*. Если подключаешь что-то из них:
- Держи ключи в **переменных окружения**, никогда в репозитории или заметках.
- Они ничего не меняют в этическом gate — платный инструмент, дотягивающийся до непубличных данных, всё равно
  вне рамок.
- Логируй расходы и ограничивай их; воспринимай стоимость как сигнал остановиться и переоценить, а не как гонку.

## Дисциплина затрат и эскалации

Бесплатные/открытые средства (§Поиск, §Загрузка, §Инфраструктура, §Публичные записи) отвечают на большинство вопросов.
Эскалируй к более тяжёлому инструментарию только когда этого требует *конкретный вопрос в рамках (scope)* — и перепроверяй
этический gate при каждой эскалации.
